# ESP32-C3 CAN Bus Communication Node

## Project Overview

A custom PCB design developed in EasyEDA featuring an ESP32-C3 microcontroller and a CAN bus transceiver interface. The project aims to provide a compact hardware platform for experimenting with CAN communication in embedded systems.

## Key Features

- ESP32-C3-based controller
- CAN bus communication interface
- CANH and CANL connector
- Power input and voltage regulation stages
- PCB layout designed using EasyEDA
- 120 Ω CAN termination resistor provision

## Hardware Design

The design includes the following functional blocks:

- Power input and protection
- Voltage regulation
- ESP32-C3 microcontroller module
- CAN transceiver interface
- CAN bus connection and termination

## Design Tool

- EasyEDA — schematic capture and PCB layout
